## Featured project

### [CloseWise](https://github.com/k5rxd/CloseWise)

A polished Android utility that closes recently active apps through Android's official controls. It includes activity-aware targeting, critical-package protection, persistent exclusions, animated progress, cancellation, OEM retry handling, and zero network access.
